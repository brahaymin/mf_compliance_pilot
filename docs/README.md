# GitHub Pages redirect stub

This folder is the intended GitHub Pages source for `brahaymin/mf_compliance_pilot`.

The live MF Feedback Pilot is the Vercel site: https://mfcompliancepilot.vercel.app/

GitHub Pages is still enabled, but after this folder is set as the Pages source
(Settings → Pages → Deploy from a branch → `main` / `/docs`) the github.io
URL serves only this redirect stub (meta refresh plus a link). The repo and
Pages itself are not deleted or disabled.

Until that setting is changed, Pages continues to publish the site root on
`main` (the same files Vercel serves). This folder is inert for Vercel, which
uses the repository root.
